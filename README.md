# Розыгрыш

React (Vite) + небольшой Node/Express сервер. Без Docker, без БД (данные в `data/*.json`).

## Страницы
- `/` — клиентская: анимация смены билетов, список призов и победителей. Последние 4 цифры телефона скрыты (маскирует сервер — полный номер в публичный API не отдаётся).
- `/login` — вход админа (логин/пароль из `.env`).
- `/admin` — загрузка Excel, призы (добавить/удалить), розыгрыш, полные данные победителей.

## Запуск
```
npm install
npm run dev        # разработка: http://localhost:5173
```

Прод:
```
npm install
npm run build
npm start          # сервер на PORT из .env (по умолчанию 3001), отдаёт dist + API
```
Nginx проксирует всё на `127.0.0.1:3001` — см. `nginx.conf.example`. Держать процесс живым можно через `pm2 start server/index.js --name lottery`.

## .env
`ADMIN_LOGIN`, `ADMIN_PASSWORD`, `JWT_SECRET`, `PORT`, `ALLOW_MULTIPLE_WINS`, `COOKIE_SECURE` (поставить `true` при https).
**Перед выкладкой смените пароль.**

## Excel (шаблон)
Колонка A — номер билета, B — ФИО, C — телефон; первая строка — заголовок. Шаблон скачивается в админке. Аннулированные билеты нужно убрать из файла заранее. Пропускаются строки без номера или телефона и дубли номера. Если ФИО не указано, билет участвует с подписью «Не указано ФИО»; итоги видны в админке.

## Честный розыгрыш (provably fair)
Источник случайности — публичный маяк [drand](https://drand.love) (League of Entropy: Cloudflare, EPFL, Protocol Labs и др.), сеть quicknet.

1. При загрузке Excel считается `listHash` — SHA-256 отсортированного списка номеров билетов. Файл номеров публичный: `/api/public/lists/<listHash>.txt` (без ФИО и телефонов).
2. «Разыграть» → сервер фиксирует и сразу показывает на сайте пул (список минус уже выигравшие), `poolHash` и номер **будущего** раунда drand (через `DRAW_DELAY_SECONDS`, по умолчанию 15 с).
3. Раунд вышел → сервер берёт число drand, проверяет BLS-подпись, вычисляет индекс по открытой формуле, победитель = `pool[index]`.
4. Отмена результата не стирает запись — она остаётся в публичном журнале с причиной.

Проверка:
- страница `/fair` — кнопка «Проверить» пересчитывает всё в браузере;
- `node scripts/verify.mjs https://ваш-сайт` — независимая проверка всех розыгрышей.

Публиковать можно файл `shared/fair.js` — это весь алгоритм (его же используют сервер, страница и скрипт).
Совет: опубликуйте `listHash` (например, в Telegram) до начала розыгрыша — тогда видно, что список не меняли.

Серверу нужен доступ в интернет к `api.drand.sh` / `drand.cloudflare.com`.

## Клиенты
`/admin/clients` — список покупателей (группировка по телефону), поиск по ФИО, телефону или номеру билета, раскрытие списка билетов, отметка победителей.

## Правило повторных побед
По умолчанию один человек (по телефону) не может выиграть два приза: все его билеты исключаются из пула (`ALLOW_MULTIPLE_WINS=true` — исключается только выигравший билет). Исключённые номера публикуются в записи розыгрыша.
